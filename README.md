# MusicDesk Releases

Public release repository for **MusicDesk**.

This repository is used to distribute Windows builds and update metadata for the MusicDesk desktop application.

## Contents

GitHub Releases published here may contain:

- `MusicDesk-Setup-x.y.z.exe`
- `MusicDesk-Setup-x.y.z.exe.blockmap`
- `latest.yml`

These files are intended for the application's update mechanism based on Electron / electron-builder / electron-updater.

## Notes

MusicDesk is an unofficial desktop client for YouTube Music and is not affiliated with Google or YouTube.

Source code does not need to be published in this repository. This repository is intended only for release artifacts and update metadata.
